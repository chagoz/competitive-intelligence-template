# Evidence Registry

*The registry of actual URLs that reveal what each competitor does, not what they say. Built once per company at profile setup. Reused every monthly reality check so sources never get rediscovered. This is what makes Layer 2 research fast instead of a fresh search every time.*

*This is a template showing the shape. The working copy lives in Notion as a database once the setup skill builds it, one row per source, per competitor.*

---

## Why this exists

The reality check compares what a competitor claims (Layer 1) against what they actually do (Layer 2). Layer 2 evidence lives in a small set of source types: help centers, review platforms, job boards, press archives. Finding these URLs takes real effort the first time. This registry means it happens once, then known addresses get revisited every month.

## How to use this

**At competitor profile setup (once per competitor):** find and record every source URL below for the new competitor. Set priority and check frequency.

**At monthly reality check:** open the registry, visit each URL by priority order, do not search from scratch.

**Ongoing:** if a URL breaks or a company restructures its site, update the entry and note the date.

---

## Source type reference

| Source type | What it reveals | Priority | Check frequency |
|---|---|---|---|
| Help center / documentation | What actually shipped, if it's documented, it exists | Critical | Monthly |
| G2 profile | Real user evidence, feature reality, pricing signals | Critical | Monthly |
| Capterra profile | SMB user reviews, ease of use, support quality | High | Monthly |
| TrustRadius profile | Enterprise user reviews, more detail than G2 | Medium | Monthly |
| Careers / job board | What they are building next, where they invest | Medium | Monthly |
| Press / newsroom page | Official announcements, confirmed partnerships | Critical | Weekly |
| LinkedIn company page | Weekly content signals, positioning shifts | Critical | Weekly |
| Product page(s) | Current claimed capabilities | High | Monthly |
| Pricing page | Cost signals, packaging changes | Medium | Monthly |

Priority legend: Critical, check every cycle without exception. High, check unless time-constrained. Medium, check when doing a full reality check pass.
